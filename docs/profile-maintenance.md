# Profile maintenance

The profile lives in `README.md`. Keep it in English and link to public projects.
The stack is based on project implementations; the AI workflow and interests were
confirmed by the owner in October 2026. Avoid ages, proficiency scores, and vague
future goals that will go stale.

## Graphics

- `assets/header-{light,dark}.svg`: original static artwork; edit both themes together.
- The stack icon rows are composed from [Skill Icons](https://github.com/tandpfun/skill-icons)
  SVGs at commit `7f7e691e71aec64e8354bf697835e009d1ad80f8`; each icon's IDs are prefixed
  within its row to prevent gradient and clip-path collisions.
  Its MIT license is preserved in `assets/skill-icons-LICENSE.txt`.
  - `assets/stack.svg`: `java,kotlin,python,go,ts,js,bash`.
  - `assets/stack-backend.svg`: `spring,hibernate,gradle,maven,fastapi,django`.
  - `assets/stack-web.svg`: `angular,react,vue,nextjs,vite`.
  - `assets/stack-data.svg`: `postgres,redis,mysql`.
  - `assets/stack-infrastructure.svg`: `docker,nginx,kubernetes,linux,githubactions`.
- `assets/clickhouse.svg`: the [Simple Icons](https://github.com/simple-icons/simple-icons)
  ClickHouse mark, placed on a matching tile. Its CC0 license is preserved in
  `assets/simple-icons-LICENSE.md`.
- `profile/stats-*.svg` and `profile/languages-*.svg`: generated by
  [GitHub Readme Stats Action](https://github.com/stats-organization/github-readme-stats-action).
  The workflow uses its pinned 2.2.0 core. Rankings and card animations are disabled.
- `profile/snake-*.svg`: generated by [snk](https://github.com/Platane/snk).
- The snake is inside a collapsed disclosure so motion is opt-in.

The expanded stack is grounded in public project dependencies and deployment files:
Mnema and Jack (Spring, JDBC/JPA, Flyway, tests), BPMN.Space (Python and React),
AeroChat and Kansoku (Go, gRPC and OpenTelemetry), Polka (MinIO/S3, k3s and
cert-manager), and earlier Django/Next.js projects. ClickHouse was requested by
the owner. The stack lists technologies used in projects, not an expertise ranking.

The workflow runs daily at 04:23 UTC (07:23 Moscow), on relevant pushes to `main`,
or manually from Actions. GitHub may delay scheduled runs. GitHub also disables
scheduled workflows after 60 days without repository activity; re-enable the
workflow if needed. Check Actions when graphics stop updating.

Generation uses a read-only `GITHUB_TOKEN`, which can access public repositories
and this profile repository. It does not need a personal token or private-repository
access. A separate publication job can write only the generated graphics to this
repository. Action references are pinned to commit SHAs. Fetch failures abort the
generation job, leaving the previous graphics in place.

Initial cards are public snapshots generated during the redesign. Language shares
measure public, non-fork repository code; notebooks are excluded to keep large
embedded notebook outputs from dominating the chart. This is not an expertise rating.

## Updating

Edit biography, project descriptions, and radar entries manually. Update the stack
icon snapshot and its license when changing tools. Validate workflow changes with
`actionlint`, then inspect README rendering in light/dark themes and on mobile.
Do not publish placeholder cards or broken asset paths.

To revert the redesign, revert its commit. The workflow only updates `profile/*.svg`;
it does not rewrite biography or project descriptions. A revert that removes the
workflow also stops its scheduled refreshes.
